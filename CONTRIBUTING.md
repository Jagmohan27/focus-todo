# Contributing to Focus Task Management

Thank you for your interest in contributing to Focus!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/Jagmohan27/focus-todo.git
   cd focus-todo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local Vite development server:
   ```bash
   npm run dev
   ```

## Pull Request Guidelines

- Ensure `npm run build` passes with zero errors before submitting PRs.
- Keep commits atomic and use standard conventional commit prefix guidelines (`feat`, `fix`, `perf`, `refactor`, `style`, `docs`).
- Maintain WCAG accessibility standards (`aria-label`, `role`, focus-visible rings).
